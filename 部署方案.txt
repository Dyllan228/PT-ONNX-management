  具体实现方案

  方案特点

  ┌────────────┬───────────────────────────────┐
  │    特性    │             说明              │
  ├────────────┼───────────────────────────────┤
  │ 多阶段构建 │ 前端构建 + 后端运行，镜像更小 │
  ├────────────┼───────────────────────────────┤
  │ 数据持久化 │ storage 目录挂载到宿主机      │
  ├────────────┼───────────────────────────────┤
  │ 单容器     │ 简单易管理，适合单人使用      │
  ├────────────┼───────────────────────────────┤
  │ 端口映射   │ 仅暴露 8000 端口              │
  └────────────┴───────────────────────────────┘

  需要创建的文件

  1. Dockerfile - 多阶段构建镜像
  2. docker-compose.yml - 容器编排（可选，但推荐）
  3. .dockerignore - 排除不需要的文件

  ---
  确认问题

  在开始实施前，需要确认：

  1. GPU 支持：是否需要 GPU 推理？（影响 PyTorch 版本选择）
    - 仅 CPU → 更小的镜像
    - 需要 GPU → 需要 NVIDIA Docker Runtime
  2. 数据持久化：storage 目录是否需要在宿主机上可访问？
    - 是 → 使用 volume 挂载
    - 否 → 数据在容器内（删除容器会丢失数据）
  3. 镜像构建位置：
    - 在当前开发机构建后上传到服务器？
    - 还是在服务器上直接构建？

  请确认以上问题，我将给出完整的实施方案。
